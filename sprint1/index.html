1. Instal·lació del sistema operatiu

En aquest apartat es documenta la instal·lació d'Ubuntu Linux en una màquina virtual, incloent-hi la configuració inicial i les comprovacions necessàries per verificar que el sistema funciona correctament.

2. Configuració de xarxa bàsica

Es comprova la configuració de l'adaptador de xarxa de la màquina virtual i l'accés a Internet. També es poden consultar les interfícies i les adreces IP amb l'ordre ip addr i provar la connectivitat amb ping.

3. Creació d'usuaris i grups

Es revisa la gestió d'usuaris i grups d'Ubuntu per organitzar els comptes i els permisos del sistema. Les operacions administratives s'han de realitzar amb els privilegis adequats.

4. Comprovació final

Per acabar, es comprova que el sistema arranca correctament, que la xarxa funciona i que els usuaris i grups s'han configurat com estava previst.

També es pot revisar el gestor d'arrencada GRUB i configurar Timeshift per crear instantànies que faciliten la recuperació del sistema davant de possibles errors.
